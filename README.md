Strike F-35

**Strike F-35** is a browser-based 3D aerial combat game developed using HTML, JavaScript, and [Three.js](https://threejs.org/).

Take control of the F-35 Lightning II and experience an interactive flight environment with 3D aircraft modeling, an immersive cockpit-style HUD, and dynamic audio.

Features

- 3D graphics powered by Three.js.
- Detailed F-35 aircraft model.
- Interactive Heads-Up Display (HUD).
- Keyboard, mouse, and touch controls.
- Custom audio effects using Web Audio API.
- Pause menu and in-game interface.
- Runs directly in the browser.

Technologies

- HTML5
- CSS3
- JavaScript
- Three.js
- Web Audio API

How to Play

1. Download this repository.
2. Open `Strike F-35.html` in a modern web browser.
3. Start the game and take control of the aircraft!

An internet connection may be required to load external libraries and fonts.

Project

Strike F-35 is an independent development project focused on creating a 3D flight and aerial combat experience directly in the browser.
